# Stillwell brand assets

## Circle mark

The canonical transparent vector is `public/brand/stillwell-mark.svg`. It is
36 × 36 units and must be used as provided: pale sage disc, outlined outer ring,
green inner ring, and clay dot. Do not recolor it or add the wordmark.

The mark colors are also available to consumers as
`tokens.color.brand.fill`, `.ring`, `.core`, and `.dot`, and as the generated
web CSS variables `--brand-fill`, `--brand-ring`, `--brand-core`, and
`--brand-dot`.

The SVG is exported from the package at
`@workspace/stillwell-design-system/brand/stillwell-mark.svg`. Platform icon
files are rasterized from this canonical vector; keep their geometry and colors
in sync with it.
