# Logos

`stillwell-mark.svg` is the Stillwell mark, converted exactly from the app's CSS mark: a 36px `brand-fill` disc with a 1px `brand-ring` edge, an 18px `brand-core` inner ring, and a 6px `brand-dot` clay point at upper right. Its colours are fixed in the file. Show it at 36px beside the lowercase `wordmark` "stillwell" on `background` or `card`; never on `primary`.
