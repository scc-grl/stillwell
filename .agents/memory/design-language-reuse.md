---
name: Reusable Stillwell design language
description: User intent for the site-derived design system
---

The user wants a design system they can “re-leverage based on this site,” meaning Stillwell Recovery's current visual language rather than a separate visual direction.

The user approved the buttons, cards, inputs, text areas, and checkboxes as the visual reference for extending the remaining component library.

**Why:** The user explicitly requested a reusable system based on the selected Stillwell site.

**How to apply:** Keep design-system extensions grounded in the site's visual identity and keep reusable presentation separate from recovery-specific account and journal behavior.
